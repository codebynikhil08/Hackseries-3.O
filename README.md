# VITALRADAR AI — Intelligent Biometric Sentinel

> A cinematic, scroll-driven 3D smartwatch experience and real-time hemodynamic command center inspired by high-end spatial product storytelling.

---

## 🌟 Overview

**VITALRADAR AI** is an autonomous cardiovascular surveillance platform engineered into aerospace-grade titanium hardware. The opening web experience features a fully real-time 3D smartwatch that responds dynamically to user scroll momentum, guiding visitors through a multi-stage narrative from dark atmospheric emergence to critical cardiac anomaly detection and seamless dashboard integration.

---

## 🎬 7-Stage Cinematic Storyline

1. **STAGE 01 — DARKNESS**: Atmospheric deep-space particle field with subtle ambient dispersion and refined editorial wordmark typography.
2. **STAGE 02 — WATCH REVEAL**: The titanium watch body emerges from the void with realistic metallic chamfer glints, knurled digital crown, and sapphire crystal reflections.
3. **STAGE 03 — HEALTH ACTIVATION**: Real-time OLED display illumination featuring live ECG waveforms, heart rate ($72\text{ BPM}$), oxygen saturation ($99\%\text{ SpO}_2$), and circular scanning vectors.
4. **STAGE 04 — SCROLL TRANSFORMATION**: Dynamic 3D rotation revealing the knurled crown and side acoustic ports, synchronized with bold editorial statements:
   - *"YOUR BODY. IN REAL TIME."*
   - *"EVERY SIGNAL MATTERS."*
   - *"DETECT THE UNEXPECTED."*
5. **STAGE 05 — DEEP SCAN**: Macro zoom onto the curved sapphire crystal with detached floating 3D biometric data rings and neural anomaly pattern forecasting.
6. **STAGE 06 — EMERGENCY EVENT**: Sudden ventricular tachycardia spike ($168\text{ BPM}$) and oxygen desaturation ($88\%\text{ SpO}_2$). Volumetric lighting and atmospheric shaders shift into controlled critical crimson red:
   - *"WHEN EVERY SECOND MATTERS."*
   - *"DETECT ANOMALIES BEFORE THEY GO UNNOTICED."*
7. **STAGE 07 — ENTER THE RADAR**: The smartwatch expands across the entire viewport, smoothly cross-fading through the sapphire lens into the interactive VITALRADAR AI Command Center.

## 🚀 Key Features

- **Procedural 3D Smartwatch in Three.js**:
  - Aerospace-grade Grade 5 titanium chassis with brushed and polished chamfer bevels.
  - Double-domed curved sapphire crystal lens with physical transmission and clearcoat reflection.
  - Ergonomic fluororubber textured straps with lug hardware.
  - Detailed 32-tooth knurled digital crown with anodized accent ring.
  - Ceramic rear dome with 4-channel pulsating green optical PPG LEDs and gold charging contacts.
- **Dynamic 60 FPS OLED Screen Texture**:
  - High-resolution HTML5 canvas rendered directly to a Three.js `CanvasTexture`.
  - Real-time procedural ECG pulse waveform with P-Q-R-S-T wave morphology.
  - Live biometric telemetry counters and circular telemetry arcs.
- **Smooth Scrubbed GSAP & Lenis Momentum Engine**:
  - 1:1 forward and backward scrub synchronization.
  - Coordinated camera position, watch rotation, field of view, and DOM text elements.
- **Synthesized Biometric Web Audio Engine**:
  - Real-time synthesized dual-phase heartbeat pulse (`lub-dub`) and emergency tachycardia warning alarms.
  - User toggle for audio playback.
- **Command Dashboard**:
  - Multi-lead cardiac oscilloscope (Lead I & Lead II / Optical PPG).
  - Neural inference confidence gauge ($98.7\%$ certainty).
  - Autonomous emergency triage protocol timeline.
  - Live simulation presets: **Resting Homeostasis**, **Cardio Workload**, and **Ventricular Tachycardia**.

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **3D Graphics**: Three.js (`three`)
- **Animation & Scroll**: GSAP + ScrollTrigger + Lenis
- **Icons**: Lucide React
- **Audio**: Web Audio API Procedural Synthesizer
- **Styling**: Modern Vanilla CSS Design System with dark luxury aesthetics

## 💻 Getting Started

### Prerequisites

- Node.js 18+ (tested with Node.js 24)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/codebynikhil08/Hackseries-3.O.git

# Navigate to project directory
cd Hackseries-3.O

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:5173` in your browser.

### Building for Production

```bash
npm run build
```
